# 遊戲介紹與操作

[回首頁](../README.md) · [安裝懶人包](QUICKSTART.md) · [遊戲介紹](GAME_GUIDE.md) · [更新紀錄](../CHANGELOG.md)

以下說明適用於新版（`main`），舊版 `37674c0` 請依該版本內的 README 與遊戲畫面操作。

## 開始遊戲

1. 雙擊 `start_game.bat`。這個檔案啟動的是四款訓練遊戲；`start_elbow.bat` 是另外的手肘偵測工具。
2. 輸入名稱建立／登入使用者，或點選已有的使用者。所有成績與回放存在這台電腦的 `data/`。
3. 按 **F1** 開啟設定，選擇攝影機、確認預覽並調整音量。若鏡頭開錯，可在這裡切換。
4. 選遊戲，再選動作組合或 Level。倒數後開始，依下方規則操作。
5. 看「剩餘時間」及左右判定提示。零、一的大視窗只有軌跡；右上角小視窗用來確認自己有沒有入鏡。
6. 時間到會背景存檔，攝影機繼續更新；遊戲零、一、二的結果頁可按 **再玩一次**；遊戲三恢復舊版，請返回選單重選。按 Esc 可返回。
7. 要分析結果，回到主選單開啟 **歷史成績**，選遊戲後切換 **最高／最近**；每個動作或 Level 分列。切換 **全部成績**，點紀錄可回放或刪除。

## 四款遊戲規則

| 遊戲 | 動作 | 時間與得分 | 過關 |
| --- | --- | --- | --- |
| 零：拳頭 | 水平、垂直、順時針、逆時針，左右共 16 種組合 | 60 秒；雙手各完成正確動作，完成確認時間差 ≤ 0.3 秒，整組 +1 | 8 分以上；達標後仍玩到時間結束 |
| 一：食指 | 同樣 16 種組合；軸向動作先握拳、伸出食指、收回 | 同上，60 秒；每組同步成功 +1 | 8 分以上 |
| 二：光劍 | 右手橘劍打左側橘球，左手藍劍打右側藍球；劍不能跨中線 | 90 秒；同色命中 +1，中央錯色 -1 並響錯誤音 | 當局可得總分的 80%，向上取整 |
| 三：三角形 | 四指皆符合舊版彎曲判定；左右各自控制 | 45 秒；藍色 +1、紅色 -1，左右各自判定 | Lv.1／2／3：15／25／35 分 |

**手勢：** 光劍維持四指伸直與掌指關節同步規則。三角形使用舊版 MCP–PIP–TIP 二維夾角判定，擴展為四指都 ≤130° 才按下，拇指不列入；不要求先抬回準備。遊戲一仍使用獨立的食指伸展規則。

**光劍中央球：** 中央可出橘球或藍球，必須用同色劍；錯色扣 1 分後該球結束，不可再補打。本版維持逐顆出球，未加入文件中尚未定案的雙球同步模式。

**分數細節：** 三角形恢復每關固定過關分數，左右各自得分，漏接藍色斷連擊但不扣分，紅色誤觸 -1。光劍維持當局可得總分的 80% 過關規則。兩款遊戲可以負分，連擊不額外加分。

**零、一難度：** 綠 Lv.1（雙手同向軸線）、黃 Lv.2（同向畫圓）、藍 Lv.3（反向畫圓）、紫 Lv.4（水平＋垂直）、灰 Lv.5（軸線＋畫圓）。全部可選，沒有新增逐級解鎖。正式選單統一 16 種雙手組合；登入頁的右手畫圓五圈測試仍保留。

**目前仍需真人測試的項目：** 握拳或水平動作遮住手指時，模型仍可能漏偵測；這次沒有宣稱更換模型或完全解決光線／遮擋。計時不會因漏偵測自動暫停。若有問題，請提供遊戲、動作組合、紀錄時間，以及回放中的「模型找到幾隻手／判定狀態」。

**可調測試參數：** 零、一位於 `common/timed_training.py`；光劍姿勢位於 `common/straight_hand.py`。三角形恢復 `games/game4_bilateral_press/config.py` 的原門檻 `FINGER_BENT_MAX_DEG = 130`，四根手指逐一使用相同舊判定，動畫固定 50°／0.15 秒，關卡 45 秒。

## 遊戲名稱與程式對照

| 畫面名稱 | 內容 | 程式資料夾 |
| --- | --- | --- |
| 遊戲零 | 左右拳心移動；16 種雙手組合，60 秒計分 | `games/game1_bilateral_vertical` |
| 遊戲一 | 食指伸展與左右手動作組合 | `games/game2_finger_vertical` |
| 遊戲二 | 光劍擊球 | `games/game3_lightsaber_marble` |
| 遊戲三 | 雙手按壓與三角形判定 | `games/game4_bilateral_press` |

資料夾編號保留開發時命名，因此比畫面顯示的遊戲編號多一。

### 遊戲零：拳頭動作

- 正式選單選擇 16 種雙手組合之一；單手五圈測試從登入頁進入。
- 水平／垂直以反向移動確認極限點，兩個相反方向的有效段算一組，不必回到固定基準。
- 畫圓從預計的 **12 點鐘位置**開始：順時針為畫面上的上→右→下→左→上，逆時針反向。
- 回到上方後，**再稍微向下**確認上方反轉點，結算當圈並開始下一圈。不要求接回原本座標，也不使用預設圓心。
- 畫圓軌跡按每隻手的圈別保留；短暫漏偵測會斷線，較長缺失或身分不確定時會重置未完成動作。
- 正式遊戲為 60 秒：雙手完成差不超過 0.3 秒，每組 +1 分，8 分過關；圓度資訊保留分析用途，不作為正式成績。

### 登入頁的「測試版右手畫圓」

先輸入使用者名稱，再按此按鈕。只使用右手順時針，**五圈結束**，使用與正式遊戲零共用的上方反轉判定。第五圈也要在回到上方後稍微往下，才能確認完成。結果頁可立即回放。

### 設定、成績及回放

- 點「設定」或按 **F1** 可調整音量、選擇攝影機；登入頁按 Esc 也可開啟設定。
- 其他畫面按 **Esc** 通常會返回上一頁。退出程式可使用登入頁右上角的按鈕。
- 主畫面的設定可管理、刪除使用者及其資料。
- 「歷史成績」可選擇紀錄進行回放或刪除。
- 回放支援暫停、慢速／加速、拖曳時間軸與事件定位；較舊紀錄可能沒有完整逐幀資訊。
- 回放保存的是軌跡、遊戲狀態與判定資料，**不是攝影機原始影片**。光劍／三角形回放會列出得分、扣分或未得分事件。

### 結算期間

動作完成後停止本次計次，攝影機畫面仍會更新。資料在背景儲存，完成後顯示結果。若存檔失敗，畫面會顯示原因，可按 **R** 重試；程式關閉時會等待已提交的存檔工作完成。
